# UI/UX Pro Max Design Principles

## 1. Visual Hierarchy & Spacing (8pt Grid System)
- Strict spacing scales: 4px, 8px, 12px, 16px, 24px, 32px, 48px, 64px.
- Use deliberate contrast: high-contrast headings, subtle subtexts (text-slate-500 / text-slate-600), crystal-clear badges.
- Elevated card design: 1px subtle borders (border-slate-100 or border-slate-200/80) paired with layered soft shadows (shadow-sm, shadow-md, shadow-xl on hover/modal).

## 2. Color Science & Tokens
- Brand Deep Blue: #0A1128, #0F172A (Navy/Slate) for trust, authority, headers and dark hero segments.
- Electric Blue: #2563EB to #1D4ED8 for vibrant CTAs, active pills, indicators, interactive states.
- Emerald Green (Rewards & Gains): #10B981 / #059669 for shopper profit badges (Gain : +25€).
- Cyan / Teal (Destinations & Routes): #06B6D4 / #0891B2 for route tags (Abidjan, Dakar).
- Clean Slate Backgrounds: #F8FAFC to #FFFFFF with glassmorphic accents (backdrop-blur-md bg-white/90).

## 3. Micro-Interactions & Polish
- Smooth transitions: transition-all duration-200 ease-out.
- Tactile hover feedback: scale up subtle hover:-translate-y-0.5, active:scale-[0.98].
- Interactive badges, pulse indicators for live / escrow states.
- Seamless modal backdrops with blur (backdrop-blur-sm bg-slate-900/40).
