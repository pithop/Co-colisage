# Web Artifacts Builder Standards

## 1. Self-Contained & Robust
- Ensure zero broken dependencies, fast Vite or Next.js build.
- Embedded high-quality SVG icons (via Lucide React) and reliable high-res image assets.
- Interactive mock workflows: real search filtering, category tabs, modal state transitions, simulated uploads, PIN code verification.
