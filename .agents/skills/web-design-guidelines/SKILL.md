# Web Design Guidelines

## 1. Typography & Hierarchy
- Font: Inter or Plus Jakarta Sans with crisp font-smoothing.
- Scale: 12px captions, 14px body-sm, 16px body, 18px-20px subheadings, 24px-36px headings, 44px-56px hero display.
- Line height: Tight on display headings (leading-tight / leading-none), comfortable on body (leading-relaxed).

## 2. Accessibility & Usability
- Minimum contrast ratio 4.5:1 for text against backgrounds.
- Explicit focus rings: focus-visible:ring-2 focus-visible:ring-blue-600.
- Interactive states: hover, active, focus, disabled clearly distinguishable.
